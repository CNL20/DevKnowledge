# FEATURE_RULES.md

- Mỗi feature lớn (Auth, Knowledge, Source, AI Pipeline, Learning, Technical English...) phải có file mô tả
  riêng trong `/docs/features/<feature>.md` trước khi implement (Part 3 sẽ tạo các file này).
- Feature không được implement nếu chưa xác nhận trong Development Roadmap (`/ai/CURRENT_STATE.md`).
- Khi 1 feature hoàn thành: cập nhật `CURRENT_STATE.md`, đánh dấu Done, ghi rõ phần chưa hoàn thiện (nếu có).
